# embeddings

🧠 NLP Word Embeddings in Google Colab 🚀


📌 Project Overview


This project explores working with word embeddings in Natural Language Processing (NLP). It involves both pre-trained embeddings and custom-trained embeddings. The work was conducted in Google Colab, leveraging a Portuguese language corpus to build and analyze embeddings.


🌟 Features


📥 Pre-trained embeddings: Uses GloVe embeddings from NILC.


🛠 Custom embeddings: Trains new word embeddings on a specific corpus.


📂 Corpus Source: The dataset was sourced from Kaggle user augustop (credit for the corpus).


📚 Tools & Libraries:


📌 gensim


🔥 torch


🤖 transformers


☁️ Google Colab


⚙️ Installation & Setup


📥 Clone the repository or download the notebook.


🛠 Install dependencies (if running locally):


pip install torch gensim transformers


📂 Open the Jupyter Notebook in Google Colab or a local Jupyter environment.


▶️ Run the notebook cells to download and process the embeddings.


🏗 Usage


📥 The notebook first downloads pre-trained GloVe embeddings from NILC.


📖 Loads the embeddings using gensim.


🛠 Trains a custom word embedding model on the selected corpus.


📊 Performs analysis and comparisons between different embeddings.
